Política de Privacidade, Segurança & LGPD (Lei nº 13.709/2018)

1. Finalidade e Base Legal: Este sistema destina-se exclusivamente ao registro, investigação e análise de incidentes e eventos adversos relacionados à assistência à saúde, em conformidade com a RDC ANVISA nº 36/2013 e os Arts. 7º (II, VIII) e 11º (II, a, f) da Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

2. Dados Coletados e Minimização: São tratados dados de identificação assistencial (iniciais/nome, prontuário, idade, sexo, diagnóstico) e dados operacionais do evento. A exibição e exportação aplicam pseudonimização por iniciais e prontuário sempre que ativada.

3. Segurança da Informação e Firebase: O acesso administrativo é protegido por autenticação (Firebase Authentication) e regras de segurança no banco de dados (Firestore Security Rules), restringindo leitura, edição e exclusão apenas a gestores autenticados.

4. Uso de Inteligência Artificial: Nenhuma informação identificável do paciente (nome completo, prontuário ou e-mail) é transmitida aos modelos de IA; apenas dados clínicos anonimizados do evento são processados.

5. Retenção e Direitos do Titular: Todas as operações ficam registradas na trilha de auditoria do NSP. Solicitações de acesso, retificação ou anonimização de registros devem ser encaminhadas ao Núcleo de Segurança do Paciente / Encarregado de Dados (DPO) da instituição.

Trilha de Auditoria LGPD (Logs de Acesso e Alteração)

Regras de Segurança Recomendadas (firestore.rules)

Copie e publique estas regras na aba Firestore Database > Rules do console do Firebase para garantir controle de acesso e conformidade LGPD:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuthenticated() {
      return request.auth != null;
    }

    function isGestor() {
      return isAuthenticated()
        && request.auth.token.firebase.sign_in_provider != 'anonymous'
        && exists(/databases/$(database)/documents/gestores_autorizados/$(request.auth.uid));
    }

    match /notificacoes/{notifId} {
      // Notificadores autenticados (inclusive sessão anônima) podem apenas criar notificações válidas
      allow create: if isAuthenticated()
        && request.resource.data.keys().hasAll(['num_evento', 'setor', 'tipo_evento', 'dano', 'lgpdConsentimento'])
        && request.resource.data.lgpdConsentimento == true;

      // Apenas Gestores autorizados podem ler, atualizar ou excluir registros clínicos
      allow read, update, delete: if isGestor();
    }

    match /configuracoes/{docId} {
      allow read: if isAuthenticated();
      allow write: if isGestor();
    }

    match /logs_auditoria_lgpd/{logId} {
      allow create: if isAuthenticated();
      allow read: if isGestor();
      allow update, delete: if false; // Logs imutáveis (LGPD)
    }

    match /gestores_autorizados/{uid} {
      allow read: if isAuthenticated() && request.auth.uid == uid;
      allow write: if false;
    }
  }
}
